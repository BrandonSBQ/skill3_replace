# Risk News Monitoring V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and run an auditable V2 post-processing pipeline that converts existing V1 RSS and extraction artifacts into conservative, Agent-ready cleaned, rejected, review, event, source-mapping, coverage, audit, and quality-report outputs.

**Architecture:** Preserve V1 acquisition code and results. Add a deterministic `risk_news_v2` package and a root CLI; process every RSS candidate as a company association, join saved extraction records, validate content, resolve entities, screen negative events, normalize dates, deduplicate at article/event levels, then route and report.

**Tech Stack:** Python 3.12, standard library, pytest; existing requests/trafilatura/gnews-decoder acquisition stack.

**Spec:** `docs/superpowers/specs/2026-11-10-risk-news-v2-design.md`

## Global Constraints

- Preserve existing runnable code and V1 results; never overwrite historical result directories.
- First V2 run is offline over existing 300-company data.
- Do not bypass robots.txt, login, paywall, CAPTCHA, or anti-bot controls.
- Do not claim formal credit assessment or verified event truth.
- `full` mode requires explicit network authorization and retains checkpoint/resume behavior.
- All statistics must be computed from emitted records.
- CSV must be UTF-8 with BOM and formula-safe; requirements comments must be ASCII.

## Review Focus

- Malformed/truncated JSONL input is counted and audited without silently corrupting output.
- Empty candidate files still emit all requested output files and stable zero-count reports.
- Same source article associated with multiple companies retains every association.
- Naive/date-only timestamps normalize deterministically and record source/precision.
- Re-running the same inputs produces stable IDs and byte-stable record ordering apart from explicit generation timestamps.
