# Risk News New-100 V2.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Execute and audit a real seven-day network stress test for 100 new, non-overlapping companies using the generalized V2 pipeline.

**Architecture:** Add a structured catalog/validator, parameterize existing search and orchestration, extend V2 entity/routing rules with catalog metadata, and add a deterministic stress-audit/report layer. Preserve V1/V2 historical outputs and use a new resumable `results_new_100_v2` directory.

**Tech Stack:** Python 3.12, requests, trafilatura, gnews-decoder, standard library, pytest, Google News RSS.

**Spec:** `docs/superpowers/specs/2026-11-10-risk-news-new-100-v2-1-design.md`

## Global Constraints

- Do not overwrite, delete, or modify `results_full_300` or `results_full_300_v2`.
- Exactly 100 new real public companies; internal duplicates and overlap with historical 300 must both be zero.
- Network access is authorized only for public Google News RSS and compliant public article retrieval.
- Keep reasonable request frequency, exponential retry, domain pacing, robots checks, checkpoints, and truthful failure states.
- All candidates route to exactly one of CLEANED, NEEDS_REVIEW, or REJECTED.
- All final statistics come from emitted files; samples are deterministic and reproducible.

## Review Focus

- Catalog aliases that equal a historical brand or a new parent/subsidiary must fail validation rather than silently pass.
- A successful zero-result RSS response must be `NO_CANDIDATE_FOUND`, while a failed request must never use that status.
- Negated phrases such as “no layoffs” and positive phrases such as “losses narrowed” must not become deterministic negative categories.
- Date conflicts and ambiguous entity context must prevent CLEANED routing without discarding the record.
- Re-running after interruption must skip successful companies/articles and keep stable candidate/association IDs.
